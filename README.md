# 现代软件开发技术 实验三：SaaS vs AI‑Agent(MCP)对比实验
## 项目介绍
本项目实现传统SaaS固定流程架构与MCP架构AI Agent的双轨对比实验，完成员工查询、工资核算、个税计算、CSV自动导出全流程。

## 环境依赖
- Python 3.10
- Ollama（部署qwen3.6:27b、qwen3.6:35b‑a3b模型）
- gradio、openai、requests

## 运行方式
1. 安装依赖：`pip install -r requirements.txt`
2. 启动应用：`python app.py`
3. 访问：`http://127.0.0.1:7860`
